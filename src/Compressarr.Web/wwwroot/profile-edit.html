Command that will run

          

            
HandBrake is given one file Compressarr generates from the built-ins plus your profiles - nothing else, so it always runs exactly what you see on the Profiles page.

        
Good to know

          

            
• Saved to %AppData%\Compressarr\Profiles\handbrake-profiles.json - it's in Compressarr's automatic backups with the rest of your settings.

            
• Names must be unique among built-ins and your profiles.

            
• Renaming a profile updates every lane and queued file that uses it.
